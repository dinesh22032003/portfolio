## 🚀 How to Run Locally

You can open `index.html` directly in any modern browser, or run a local lightweight dev server:

### Option A: Python Built-in Server
```bash
python -m http.server 3000
```
Open `http://localhost:3000` in your browser.

### Option B: Node / npx
```bash
npx -y serve .
```

## 🌐 Deploy to Vercel (1-Click)

1. Push this folder to your GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Dinesh Rajkumar portfolio"
   git branch -M main
   git remote add origin https://github.com/dinesh22032003/portfolio.git
   git push -u origin main
   ```
2. Go to [Vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository.
4. Click **Deploy** — Vercel will automatically detect static files and deploy them globally with instant SSL!
